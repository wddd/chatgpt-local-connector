# Arc.ContextSettings

A gear opens a Popover containing SingleChoice. Only task bubble width and side-panel width use this composite in the product. Owners retain the existing preference keys and mutations. Escape restores trigger focus; no settings are created by the composite.

## Props

`label: string`, `value`, `options: { value, label }[]`, `onChange(value)`, optional `revealed`.

## Mounts

Exported through `ui/design-mount.ts`. Secondary icons also reveal on focus-within and coarse pointers. Icon controls expose a name and tooltip.
